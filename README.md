# agent-skills
存储自己创建的agent-skills

## 已提交的技能

### 1. yt-dlp - 视频下载工具

**功能说明：**
该技能支持从数千个网站下载视频内容，包括 YouTube、Bilibili、Vimeo、Twitch 等主流平台。同时具备提取音频、自定义下载格式和质量、下载字幕等功能。

**使用方法：**
提供视频链接并说明下载需求即可，例如：
- "下载此视频：[视频链接]"
- "提取该视频的音频：[视频链接]"
- "下载视频并保存为 mp4 格式：[视频链接]"

---

### 2. pygui-auto - 桌面自动化工具

**功能说明：**
该技能提供桌面操作自动化功能，包括启动应用程序、文本输入、鼠标点击、键盘快捷键操作、文件创建等，可自动化执行各类桌面任务。

**使用方法：**
直接描述所需操作即可，例如：
- "打开记事本"
- "启动桌面上的新师慧成快捷方式"
- "访问B站网站"
- "创建文件并写入指定内容"

---

### 3. video-voice-processor - 视频音频处理与语音识别工具

**功能说明：**
该技能提供完整的视频和音频处理工具包，支持提取视频元数据、从视频中提取音频、格式转换以及语音识别功能。语音识别支持两种方式：
- **OpenAI Whisper**：本地离线识别，支持 99+ 种语言，无需 API 密钥
- **阿里云 Dashscope**：云端识别，支持中英文，需要 API 密钥

**使用方法：**
直接描述所需操作即可，例如：
- "获取这个视频的信息：[视频路径]"
- "从视频中提取音频：[视频路径]"
- "将视频转换为 MP4 格式：[视频路径]"
- "识别音频文件中的语音内容：[音频路径]"
- "提取视频中的语音并转换为文字：[视频路径]"
